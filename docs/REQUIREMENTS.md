# Public requirements summary

The user requested a local agent Skill that combines a paper project's preparation state with Zhouyi/Yijing cultural references to recommend several submission dates, exact operational times and optional facing directions for the next week. They then requested a detailed implementation guide, richer experience, a self-contained GitHub-ready folder, bilingual switchable README files and promotional images requested as Image2.

Required experience includes comparison, natural-language adjustments, plan selection and locking, review after changes, preparation backplanning, a direction schematic, submission records, cultural interpretation depth and supported-method preferences. External reminders are optional and must reflect actual provider capability.

The full private historical conversation is not distributed. This public summary replaces that raw transcript reference in the portable design guide. All example projects and deadlines in this package are synthetic. No user manuscript, birth data, private vault paths or account information is needed for these examples.
